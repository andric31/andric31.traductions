✨ Fonctionnalités

L’extension complète F95Zone sans remplacer son interface. Elle s’appuie sur ma liste de traductions et sur le Viewer pour afficher rapidement les informations utiles d’un jeu.

🎮 Threads et vignettes

Ajout d’une icône et d’informations visuelles directement sur les pages de F95Zone.

🪟 Fiche rapide

Affiche le jeu, sa traduction, son statut, les liens disponibles et une galerie sans quitter la page.

👥 Multi-traducteurs

Prise en charge de plusieurs traducteurs et accès à leur page Viewer.

✅ État de la traduction

Signalement visuel lorsque la traduction correspond à la version du jeu ou lorsqu’une mise à jour est nécessaire.

🚀 Installation

Téléchargez la version correspondant à votre navigateur depuis le dossier MEGA. Les versions Chromium et Firefox sont suivies séparément : leur numéro peut être différent si un correctif ne concerne qu’un seul navigateur.

🌐 Chrome / Edge / Brave

  1. Décompressez l’archive Chrome.
  2. Ouvrez chrome://extensions/ (ou la page équivalente du navigateur).
  3. Activez le Mode développeur.
  4. Cliquez sur Charger l’extension non empaquetée et sélectionnez le dossier décompressé.

🔴 Opera

  1. Décompressez l’archive Chrome / Chromium.
  2. Ouvrez opera://extensions.
  3. Activez le Mode développeur.
  4. Choisissez Charger l’extension non empaquetée.

🦊 Firefox

  1. Téléchargez le fichier Firefox fourni dans le dossier MEGA.
  2. Si un fichier .xpi signé est fourni, glissez-déposez-le dans Firefox.
  3. Confirmez avec Ajouter.
  4. Épinglez l’extension si vous souhaitez accéder rapidement à ses réglages.
Après une mise à jour : rechargez l’extension puis actualisez les onglets F95Zone déjà ouverts afin que les nouveaux scripts soient utilisés.

⚙️ Réglages

Le menu de l’extension permet notamment d’adapter son comportement à votre utilisation :

  • taille de l’icône affichée sur les vignettes ;
  • affichage et agrandissement de la galerie / fiche rapide ;
  • choix de l’action au clic : accès direct, traduction ou menu ;
  • accès aux différentes pages du Viewer et aux traducteurs disponibles ;
  • vérification manuelle des mises à jour depuis Réglages.

🔄 Mises à jour de l’extension

Depuis la v5.0, l’extension peut signaler automatiquement qu’une nouvelle version est disponible. Chrome / Chromium et Firefox sont vérifiés indépendamment afin de ne pas annoncer un correctif destiné à l’autre navigateur.

  • notification dans le menu de l’extension ;
  • petite annonce directement sur F95Zone, même si l’extension n’est pas épinglée ;
  • bandeau discret dans les fiches rapides tant que la mise à jour n’est pas installée ;
  • Plus tard reporte les annonces pendant 24 heures ;
  • Ne plus afficher pour cette version masque les alertes, mais pas le bandeau permanent des fiches.
Aucune installation automatique : l’extension avertit uniquement et ouvre le dossier MEGA lorsque vous le demandez.

❓ FAQ / dépannage

Un jeu vient d’être ajouté ou mis à jour mais rien n’apparaît encore ?

Un délai peut exister entre la mise à jour des données et leur affichage sur F95Zone. Patientez quelques minutes puis actualisez la page.

Est-ce compatible avec d’autres extensions F95Zone ?

Oui. L’extension fonctionne indépendamment et peut afficher ses propres icônes en plus de celles d’autres extensions.

Le bouton Discord est grisé ?

Le lien est vérifié au moment d’ouvrir la fiche. S’il n’existe pas, le bouton reste désactivé ; en cas d’erreur temporaire, un bouton permet de réessayer.

L’extension fonctionne-t-elle sur Android ?

Elle est prévue avant tout pour les navigateurs de bureau. Le fonctionnement sur navigateur mobile n’est pas garanti.
