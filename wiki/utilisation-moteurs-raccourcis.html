Commandes par défaut

Ren’Py

01

Ces commandes sont celles de l’interface habituelle ; un jeu peut les modifier ou désactiver certaines fonctions.

Commandes · Ren’Py
ActionTouche ou chemin à suivre
SauvegarderÉchap ou clic droit → Sauvegarder / Save → choisir un emplacement.
ChargerMenu → Charger / Load → choisir une sauvegarde. Les boutons Q.Save et Q.Load, s’ils sont présents, servent à la sauvegarde et au chargement rapides.
Plein écranF ; les versions récentes acceptent aussi F11 et Alt + Entrée. Même commande pour revenir en fenêtre.
ParamètresMenu → Préférences / Preferences : affichage, volume, vitesse du texte et lecture automatique.
AvancerClic gauche ou Entrée. Espace fait avancer le texte sans valider les choix.
Retour en arrièrePage préc. / PgUp ou molette vers le haut, si le retour est autorisé. Page suiv. / PgDn refait le chemin parcouru.
Passer le texteCtrl maintenu pour accélérer ; Tab active ou désactive le défilement rapide, selon les préférences de lecture.
Masquer le texteH ou clic molette ; recommencer pour le réafficher.
Capture d’écranS prend une image de l’écran. Cette touche ne sauvegarde pas la partie.

Pour une sauvegarde durable, utilise un emplacement manuel. Il n’y a pas de touche de sauvegarde rapide commune à tous les jeux Ren’Py.

Commandes standard MV / MZ

RPG Maker MV / MZ

02

Ces touches concernent les jeux MV et MZ. Les plugins peuvent changer les menus, les touches et l’accès aux sauvegardes.

Commandes · RPG Maker MV / MZ
ActionTouche ou chemin à suivre
SauvegarderÉchap ou X → Sauvegarder / Save → emplacement. Le jeu peut imposer un point de sauvegarde.
ChargerÉcran-titre → Continuer / Continue → choisir sa partie.
Plein écranF4 pour basculer entre fenêtre et plein écran. F3 change l’étirement de l’image.
ParamètresMenu du jeu ou écran-titre → Options.
Déplacement et validationFlèches pour se déplacer ; Z, Entrée ou Espace pour valider. Maj / Shift pour courir.
Menu / annulerÉchap, X ou clic droit. Q / Page préc. et W / Page suiv. changent de page lorsque le menu le permet.

F5 recharge le jeu : la progression non sauvegardée peut être perdue. Ce n’est pas une touche de sauvegarde rapide. Pour XP, VX ou VX Ace, consulte l’aide du jeu : les raccourcis système diffèrent.

Commandes définies par le jeu

Unity

03

Unity ne fixe pas les touches de sauvegarde, de pause ou de paramètres pour tous ses jeux. Suis les indications de l’écran-titre ou du tutoriel.

Commandes · Unity
ActionTouche ou chemin à suivre
Sauvegarder / chargerChercher Save / Load / Continue dans le menu. Certains jeux fonctionnent uniquement avec des sauvegardes automatiques ou des points de contrôle.
Plein écranAlt + Entrée sous Windows si le jeu autorise la bascule. Sinon, chercher Settings → Graphics / Display → Fullscreen.
ParamètresMenu Options / Settings. Échap ouvre souvent la pause, mais cela dépend du jeu.
RaccourcisLire Controls / Key Bindings. F5 et F9 ne sont pas des touches de sauvegarde / chargement garanties par Unity.

Un jeu peut proposer « Windowed », « Fullscreen » ou « Borderless ». Les modes réellement disponibles dépendent de sa configuration.

Commandes définies par le jeu

Godot

04

Le créateur du jeu choisit les actions et les touches associées. On ne peut donc pas déduire sa touche de pause ou de sauvegarde à partir du moteur seul.

Commandes · Godot
ActionTouche ou chemin à suivre
Sauvegarder / chargerChercher Save / Load / Continue ou suivre les points de sauvegarde indiqués. Il n’y a pas de touche de sauvegarde universelle.
Plein écranChercher Fullscreen / Display / Video dans les paramètres. F11 ou Alt + Entrée ne sont pas garantis : le jeu doit les prendre en charge.
ParamètresÉcran-titre ou bouton de pause → Options / Settings. Consulter l’aide pour connaître la touche d’ouverture.
RaccourcisChercher Controls / Help ou le fichier Readme fourni avec le jeu.

Pour une version jouée dans un navigateur, consulte aussi la fiche HTML5 / jeux web.

Interface et touches personnalisables

TyranoBuilder / TyranoScript

05

Le jeu peut proposer une barre de boutons permanente ou un menu. Les raccourcis clavier dépendent du projet : utilise d’abord les commandes affichées.

Commandes · TyranoBuilder / TyranoScript
ActionTouche ou chemin à suivre
Sauvegarder / chargerBoutons Save et Load, directement ou dans Menu. Quick Save / Quick Load peuvent aussi être proposés.
Plein écranBouton Fullscreen ou icône d’agrandissement, si ajouté par le créateur. En version navigateur, voir la fiche HTML5 / jeux web.
ParamètresChercher Config / Settings / Options dans le menu ou sur l’écran-titre.
LectureCliquer pour avancer ; utiliser Auto, Skip et Backlog lorsqu’ils sont affichés. Les touches pour ces actions peuvent varier.

Ne suppose pas que S, F ou Échap ont le même effet que dans Ren’Py. L’aide du jeu reste la référence pour son clavier.

Commandes KAG · selon le jeu

KiriKiri / KAG

06

Les commandes ci-dessous sont les repères du KAG classique. Un jeu KiriKiri peut utiliser une interface très différente.

Commandes · KiriKiri / KAG
ActionTouche ou chemin à suivre
Sauvegarder / chargerUtiliser Save / Load. Dans le mode de sauvegarde libre de KAG, S sert à sauvegarder et L à charger ; seulement si ce mode est utilisé.
Plein écranChercher Fullscreen dans Config / Display ou le menu de la fenêtre. Le raccourci dépend du jeu.
ParamètresOuvrir Config / Options. Clic droit ou Échap affiche l’historique ou exécute l’action prévue par le jeu ; ce n’est pas forcément le menu.
LectureClic gauche, Entrée ou Espace pour avancer. R affiche l’historique ; A lance la lecture automatique dans le KAG standard.

Attention à F : dans le KAG standard, cette touche avance jusqu’au prochain choix ou texte non lu. Elle ne commande pas le plein écran.

Selon le modèle d’interface

Visual Novel Maker

07

Les menus peuvent être construits avec des modèles ou entièrement personnalisés. Il n’y a pas de raccourci joueur à supposer identique dans tous les jeux.

Commandes · Visual Novel Maker
ActionTouche ou chemin à suivre
Sauvegarder / chargerChercher Save / Load dans le menu ou la barre de jeu. L’accès peut être désactivé pendant certaines scènes.
Plein écranOuvrir Settings / Options, puis chercher Fullscreen ou le réglage d’affichage, s’il est proposé.
ParamètresBouton Settings / Config du menu ou de l’écran-titre : texte, son, lecture automatique, selon l’interface.
RaccourcisConsulter Help / Controls ou le fichier d’aide fourni. Les touches de l’éditeur VNM ne décrivent pas les commandes du jeu exporté.

Si un bouton de sauvegarde est grisé, attends la fin de la scène ou utilise un point de sauvegarde prévu par le jeu.

Système de base · selon la version

WOLF RPG Editor

08

Le système de base utilise un clavier proche de RPG Maker, mais les touches d’affichage n’ont pas le même rôle.

Commandes · WOLF RPG Editor
ActionTouche ou chemin à suivre
Sauvegarder / chargerOuvrir le menu avec Échap ou X, puis chercher Save / Load selon le jeu. Certains titres utilisent des points de sauvegarde.
Plein écran / tailleChercher le mode d’affichage dans Config.exe si ce programme est fourni. F4 change la taille de la fenêtre ; les versions récentes peuvent aller jusqu’à un pseudo plein écran. F11 agrandit la fenêtre sur les versions qui le prennent en charge.
ParamètresMenu Options / Config du jeu, ou Config.exe pour les réglages d’affichage et de son disponibles.
JouerFlèches pour se déplacer ; Z, Entrée ou Espace pour valider. X / Échap pour annuler. Maj ou C : action secondaire, selon le jeu.

F12 peut ramener à l’écran-titre si la fonction est active. Sauvegarde avant de l’utiliser. F4 n’est donc pas l’équivalent exact de son usage dans RPG Maker MV/MZ.

Navigateur · repères Windows

HTML5 / jeux web

12

HTML5 désigne une technologie web. Le jeu peut utiliser différents moteurs : ses boutons et ses sauvegardes dépendent de son interface.

Commandes · HTML5 / jeux web
ActionTouche ou chemin à suivre
Sauvegarder / chargerUtiliser Save / Load dans le jeu. Si un bouton Export / Save to file existe, garder aussi une copie téléchargée ; Import / Load from file permet de la relire.
Plein écranF11 dans Chrome sous Windows pour agrandir le navigateur ; F11 à nouveau pour revenir. Le bouton plein écran du jeu, s’il existe, peut agrandir seulement la zone de jeu.
ParamètresBouton Options / Settings à l’intérieur du jeu. Le menu du navigateur règle le navigateur, pas les options de la partie.
RaccourcisCliquer d’abord dans le jeu. Certaines touches sont interceptées par le navigateur ou ne sont disponibles qu’avec un clavier physique.

Ctrl + S enregistre généralement la page web, pas la partie. F5 recharge la page. Une sauvegarde stockée dans le navigateur peut disparaître si ses données sont effacées ; exporte-la si le jeu le permet.

Electron

13

Commandes · Electron

ParamètresMenu interne Options / Settings du jeu.
RaccourcisSuivre l’aide du jeu ou les indications de la barre de menus. F11 n’est pas une garantie pour toutes les applications Electron.

Garder sa progression

Bien sauvegarder sa partie

Sauvegarde manuelle

Ouvre Save, choisis un emplacement et confirme. Vérifie ensuite la date, l’heure ou la vignette affichée. Alterne entre plusieurs emplacements avant les choix importants.

Sauvegarde rapide

Q.Save / Quick Save enregistre rapidement. Q.Load / Quick Load recharge : il peut remplacer la progression en cours par une partie plus ancienne.

Sauvegarde automatique

Auto Save dépend du jeu. Elle ne signifie pas forcément que chaque action est enregistrée. Attends la fin de l’indicateur de sauvegarde avant de quitter.

Avant une mise à jour du jeu, garde une copie de tes sauvegardes. Leur emplacement et leur compatibilité dépendent du titre. Pour un jeu web, utilise l’export de sauvegarde lorsqu’il est proposé.

Une touche ne répond pas ?

Les touches F1 à F12 règlent le son ou la luminosité

Sur certains claviers, maintiens Fn avec la touche souhaitée, par exemple Fn + F4. Le fonctionnement dépend du clavier.

Le clavier ne contrôle pas le jeu

Clique dans la fenêtre du jeu, quitte un champ de saisie éventuel et réessaie. Vérifie le menu Controls et la disposition AZERTY / QWERTY. Utilise les flèches quand elles sont proposées.

Le bouton de sauvegarde est absent ou grisé

Le jeu peut bloquer la sauvegarde pendant un dialogue, un combat ou une scène. Cherche un point de sauvegarde ou attends une phase où le menu est disponible. La touche seule ne peut pas contourner cette limite.

Le plein écran ne fonctionne pas

Vérifie que tu utilises la bonne fiche moteur. Cherche Display / Graphics / Fullscreen dans les options. Agrandir une fenêtre, étirer l’image et passer en plein écran sont trois actions différentes ; certains jeux n’en proposent qu’une partie.

Je joue sur Mac ou Linux

Les fiches prennent Windows comme repère. Utilise les commandes affichées dans le jeu et sa documentation pour ton système ; une combinaison avec Alt ou une touche de fonction peut être différente.

Je joue sur Android ou avec JoiPlay

Utilise les boutons du jeu ou les touches virtuelles configurées dans JoiPlay. Les commandes PC ne sont pas toujours disponibles au toucher. Consulte Ren’Py sur Android avec JoiPlay ou RPG Maker sur Android avec JoiPlay.
