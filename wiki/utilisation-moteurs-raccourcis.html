Les commandes à retrouver rapidement

En un coup d’œil

Choisis le moteur indiqué sur la fiche de ton jeu. Les touches peuvent varier d’un jeu à l’autre. Si une touche ne répond pas, utilise le bouton correspondant dans le menu.

Ren’Py

01
Commandes · Ren’Py
Je veux…Comment faire
SauvegarderÉchap ou clic droit → Sauvegarder / Save → choisis une case.
Charger une partieMême menu → Charger / Load → choisis ta sauvegarde.
Plein écranF. Appuie à nouveau sur F pour revenir en fenêtre.
Ouvrir les paramètresÉchap ou clic droit → Préférences / Preferences.
Avancer dans le texteClic gauche, Entrée ou Espace. Pour valider un choix : clic gauche ou Entrée.
Relire / revenir en arrièreMolette vers le haut ou Page préc. (PgUp), si le jeu le permet.
Passer le texteMaintiens Ctrl pour accélérer. Tab active ou arrête le défilement rapide.
Masquer les dialoguesH. Appuie à nouveau pour les réafficher.

À retenir : S fait une capture d’écran. Pour enregistrer ta partie, utilise Sauvegarder.

Commandes · RPG Maker MV / MZ
Je veux…Comment faire
SauvegarderÉchap ou X → Sauvegarder / Save → choisis une case.

WOLF RPG Editor

08
Commandes · WOLF RPG Editor
Je veux…Comment faire
Sauvegarder / chargerÉchap ou X → cherche Sauvegarder / Save. Pour reprendre, choisis Charger / Load ou Continuer si proposé.

Garder sa progression

Save : sauvegarder

Choisis une case et confirme. Garde plusieurs sauvegardes si tu veux revenir avant un choix important.

Load : reprendre

Choisis la sauvegarde que tu veux reprendre. Tu reviens au moment où elle a été enregistrée.

Q.Save / Q.Load

Sauvegarde rapide / chargement rapide, quand ces boutons sont présents. Q.Load reprend la dernière sauvegarde rapide.

Si le jeu sauvegarde automatiquement, attends la fin de l’icône de sauvegarde avant de quitter.

Besoin d’un coup de main ?

Une touche ne répond pas

Clique d’abord dans la fenêtre du jeu. Pour les touches F1 à F12, il faut parfois maintenir Fn sur un ordinateur portable. Si cela ne marche pas, utilise le bouton du menu.

Je ne peux pas sauvegarder

Certains jeux empêchent de sauvegarder pendant une scène ou un combat. Attends la fin, ou cherche un point de sauvegarde dans le jeu.

Je ne trouve pas le plein écran

Dans les options, cherche Affichage / Display, Vidéo / Video ou Fullscreen. Tous les jeux ne proposent pas ce réglage.

Je joue sur Android ou avec JoiPlay

Utilise les boutons tactiles du jeu. Avec JoiPlay, tu peux aussi utiliser ses touches à l’écran. Consulte les guides Ren’Py sur Android ou RPG Maker sur Android.
